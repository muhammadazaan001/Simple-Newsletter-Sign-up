# Newsletter Sign-Up Form

A simple and stylish newsletter sign-up form built using **HTML5 and CSS3**. This project was created to practice form elements, CSS styling, Flexbox, and interactive button effects.

## Features

- Email input with built-in HTML validation
- Required fields for user information
- Styled input fields with rounded corners
- Custom Subscribe button with a hover effect
- Flexbox layout for alignment
- Custom background and button colors

## Technologies Used

- **HTML5** — Form structure, input fields, and validation
- **CSS3** — Flexbox, colors, padding, margins, borders, and hover effects

## Form Fields

- Email Address
- First Name
- Last Name
- Country
- Organization

## What I Learned

- Creating forms using HTML
- Using different input types
- Applying the `required` attribute
- Centering elements with CSS Flexbox
- Styling input fields and buttons
- Using the `:hover` pseudo-class

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
